# Masakan Indonesia

Website statis sederhana bertema dokumentasi masakan khas dan kuliner tradisional Indonesia yang dibangun menggunakan HTML5 semantik dan CSS3 eksternal.

## Struktur Halaman
- `index.html` : Beranda dan sorotan masakan populer
- `menu.html` : Indeks daftar hidangan khas daerah
- `daerah.html` : Eksplorasi masakan berdasarkan daerah asal
- `About.html` : Profil pengembang (identitas mahasiswa)
- `kontak.html` : Informasi kontak dan tautan repositori
- `css/style.css` : Lembar gaya (CSS) eksternal
